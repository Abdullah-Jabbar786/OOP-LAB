## 🎯 About

This repository contains comprehensive **Object-Oriented Programming (OOP)** laboratory work completed during the 2nd semester at **FAST-NUCES** (BCS-H program). It includes hands-on assignments covering fundamental OOP principles, design patterns, and practical C++ implementations.

The work demonstrates proficiency in:
- Class design and object instantiation
- Inheritance and polymorphism
- Encapsulation and abstraction
- Exception handling
- Memory management

## 🔑 Concepts Covered

### Core OOP Principles
✅ **Classes & Objects** - Creating and managing object instances  
✅ **Constructors & Destructors** - Initialization and cleanup  
✅ **Encapsulation** - Public/Private/Protected access levels  
✅ **Inheritance** - Code reuse through class hierarchies  
✅ **Polymorphism** - Runtime method resolution  
✅ **Abstraction** - Hiding implementation complexity  
✅ **Operator Overloading** - Custom operator behaviors  
✅ **Exception Handling** - Try-catch error management  

### Advanced Concepts
- Virtual functions and abstract base classes
- Multiple inheritance (pros & cons)
- Friend classes and functions
- Copy constructors and assignment operators
- Static members and methods

## 🚀 How to Use

### Prerequisites
- C++ compiler (GCC, Clang, or MSVC) with C++11 support
- Text editor or IDE (VS Code, CodeBlocks, Visual Studio)

### Compilation & Execution

**For individual files:**
```bash
# Compile
g++ -std=c++11 labX.cpp -o labX

# Run
./labX
```

**With Makefile (if provided):**
```bash
make          # Compile all
make run      # Compile and run
make clean    # Clean build files
```

### Exploring the Code
1. Open any `.cpp` file in your editor
2. Read the comments explaining the OOP concepts
3. Compile and run to see output
4. Modify and experiment with the code

## 💡 Key Learnings

### What I Learned

1. **Object-Oriented Thinking** - Breaking problems into objects with clear responsibilities
2. **Design Patterns** - Recognizing and implementing common OOP patterns
3. **Memory Management** - Understanding heap vs. stack allocation
4. **Code Organization** - Structuring large projects with multiple classes
5. **SOLID Principles** - Writing maintainable and scalable code
6. **Testing & Debugging** - Validating object behavior and fixing issues
